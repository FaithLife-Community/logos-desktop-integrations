Logos desktop integrations for Logos Bible Software on Linux under [Ou Dedetai](https://github.com/FaithLife-Community/OuDedetai), for KDE Plasma 6 and GNOME.

## New in 0.5.1

- **Ou Dedetai can tell you when there's an update.** The installer now records which version is installed (`~/.local/share/logos-plasma/VERSION`), so Ou Dedetai can offer to update the integrations when a newer release is out. The self-test report shows the installed version too.
- Nothing else changes. Installs from before 0.5.1 have no version recorded, so Ou Dedetai will offer this release to them as an update.

## Install or update

    curl -fsSL https://raw.githubusercontent.com/FaithLife-Community/logos-desktop-integrations/main/get.sh | sh

Then check everything with `python3 ~/.local/share/logos-plasma/logos_plasma.py --selftest`. To uninstall: `sh ~/.local/share/logos-plasma/uninstall.sh`.
