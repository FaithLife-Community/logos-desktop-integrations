Logos desktop integrations for Logos Bible Software on Linux under [Ou Dedetai](https://github.com/FaithLife-Community/OuDedetai). This release is for **KDE Plasma 6**; GNOME support is coming.

## Fixed in 0.4.1

- **The look-up shortcut is now Alt+Shift+L.** Meta+Alt+L is already taken on some systems, and Plasma then silently drops ours, so the shortcut did nothing. Updating sets Alt+Shift+L if no key is bound; a key you've chosen yourself is kept. You can change it in System Settings → Keyboard → Shortcuts → "Look up in Logos".
- **Looking up highlighted text needs `wl-clipboard`.** The installer now says if it's missing (e.g. `sudo apt install wl-clipboard`). Without it, only copied text can be looked up.
- **The self-test checks the shortcut properly:** it shows the key that's bound (or that it was cleared), and whether highlighted text can be read.

## Install or update

Requires Plasma 6, Ou Dedetai, Python 3.11+, `python3-dbus`, `python3-gi` and, for looking up highlighted text, `wl-clipboard`:

    curl -fsSL https://raw.githubusercontent.com/FaithLife-Community/logos-desktop-integrations/main/get.sh | sh

Then check everything with `python3 ~/.local/share/logos-plasma/logos_plasma.py --selftest`. To uninstall: `sh ~/.local/share/logos-plasma/uninstall.sh`. The [KRunner guide](https://github.com/FaithLife-Community/logos-desktop-integrations/blob/main/docs/krunner.md) covers every command.

Logos's data is only ever read, never changed; book contents aren't read at all. Community project, not affiliated with or supported by Faithlife.
