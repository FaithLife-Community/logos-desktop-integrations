Logos desktop integrations for Logos Bible Software on Linux under [Ou Dedetai](https://github.com/FaithLife-Community/OuDedetai). This release is for **KDE Plasma 6**; GNOME support is coming.

## New in 0.3.0

- **Copying verses now works:** `cv John 3:16-18` puts the passage on the clipboard in your preferred Bible, formatted the way you last set up Logos's Copy Bible Verses tool (quotes, dashes, Greek and Hebrew intact).
- **Opening a layout at a passage now works:** `lay passage John 3:16` loads the layout and moves its linked Bible, and everything linked to it, to that passage.

Both failed in 0.2.0 with "Invalid procedure call or argument". Under Wine, Logos's automation interface rejects objects passed by reference; they're now passed by value.

## Also in this series (0.2.0)

- **Your saved layouts** from KRunner: `lay` lists them, `lay dev` filters them, Enter switches Logos to one.
- **Verse of the Day widget** can open a saved layout when clicked (Settings → Click opens → A saved layout).
- **Showcase widget:** choose the shelf per widget: unread and well-rated books (default), commentaries for your sermon, or both, half and half.
- **One-command install and update**, and an uninstaller that stays installed.
- The project is now **logos-desktop-integrations** (old links redirect).

Layouts and verse copying use Logos's documented automation (COM) interface. The installer registers it so Wine can find it ("Logos COM API: registered" or "already registered").

## Install or update

Requires Plasma 6, Ou Dedetai, Python 3.11+, `python3-dbus` and `python3-gi`:

    curl -fsSL https://raw.githubusercontent.com/FaithLife-Community/logos-desktop-integrations/main/get.sh | sh

Then check everything with `python3 ~/.local/share/logos-plasma/logos_plasma.py --selftest`. To uninstall: `sh ~/.local/share/logos-plasma/uninstall.sh`. The [KRunner guide](https://github.com/FaithLife-Community/logos-desktop-integrations/blob/main/docs/krunner.md) covers every command.

Logos's data is only ever read, never changed; book contents aren't read at all. Community project, not affiliated with or supported by Faithlife.
