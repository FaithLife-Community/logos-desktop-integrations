Logos desktop integrations for Logos Bible Software on Linux under [Ou Dedetai](https://github.com/FaithLife-Community/OuDedetai), now for **KDE Plasma 6 and GNOME**. The installer picks the desktop you're running.

## New in 0.5.0: GNOME

- **Search Logos from the Activities overview.** Press Super and type any of the commands: `John 3:16`, `o John 3:16`, `s grace`, `cv John 3:16`, `lay`, `fb moses`, `today`, `rp`, `logos` for the list. Results show under Logos's name and icon.
- **Look up in Logos (Alt+Shift+L):** select or copy a Bible reference in any app and press the key. It's a normal custom shortcut in Settings → Keyboard; if Alt+Shift+L is already taken, the installer leaves it for you to choose.
- **Reading-plan reminders** as GNOME notifications.
- No widgets, since GNOME doesn't have them. When Logos is behind other windows, GNOME shows "Logos is ready" rather than bringing it forward, as it does for every app.
- After the first install, log out and back in once so GNOME's search finds Logos.

See the [GNOME guide](https://github.com/FaithLife-Community/logos-desktop-integrations/blob/main/docs/gnome.md), which includes a test checklist. GNOME support is new and hasn't yet had wide testing: reports welcome.

## Also

- Copying verses (`cv`) and the look-up shortcut use `wl-clipboard` or `xclip` when Plasma's clipboard service isn't there.
- Reading highlighted text asks only for text, so a selected image is ignored.
- Nothing changes on Plasma apart from the version number.

## Install or update

Requires KDE Plasma 6 or GNOME, Ou Dedetai, Python 3.11+, `python3-dbus`, `python3-gi` and, for looking up highlighted text, `wl-clipboard`:

    curl -fsSL https://raw.githubusercontent.com/FaithLife-Community/logos-desktop-integrations/main/get.sh | sh

Then check everything with `python3 ~/.local/share/logos-plasma/logos_plasma.py --selftest`. To uninstall: `sh ~/.local/share/logos-plasma/uninstall.sh`.

Logos's data is only ever read, never changed; book contents aren't read at all. Community project, not affiliated with or supported by Faithlife.
